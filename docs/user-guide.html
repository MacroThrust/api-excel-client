MT Data Connector

User guide — using the add-in in Excel

This page is for people who use the add-in in Excel. Developers and admins should read the project README on GitHub.

What this add-in does

MT Data Connector pulls data from your organization’s API into Excel with formulas (for example =MT.GETSOURCES()). After sign-in, it can register extra functions from your API’s OpenAPI spec—only for endpoints your account may call.

Before you start

  • Microsoft Excel (web or desktop with Office Add-ins)
  • The add-in manifest URL or a deployment from your IT team
  • Permission to sign in with Microsoft and your organization’s identity provider

Install or open the add-in

Deployed by IT

  1. Open Excel and a workbook.
  2. Go to Insert → Office Add-ins / My Add-ins.
  3. Open MT Data Connector.

Sideload yourself (Excel on the web)

  1. Open Excel on the web.
  2. Insert → Office Add-ins → Upload My Add-in.
  3. Paste your manifest URL, for example:
https://<owner>.github.io/<repo>/manifest.xml

Excel desktop

Download manifest.xml from the same host, then follow your organization’s trusted-catalog or sideload instructions. Restart Excel if required.

First-time setup

  1. Open the task pane from the ribbon (MT Data Connector or MT Menu).
  2. Sign in and complete Microsoft and Authentik prompts if shown.
  3. Reload API functions if needed (task pane button, ribbon, or =MT.RELOADFUNCTIONS()).
  4. Try a formula, e.g. =MT.STATUS() or =MT.GETSOURCES().

Built-in functions

All functions use the MT namespace:

FormulaPurpose
=MT.GETSOURCES([filter])List data sources
=MT.GETRECORDS(…)Fetch records
=MT.GETRECORD(…)Single record
=MT.GETSCHEMA(source)Source schema
=MT.SEARCH(…)Search
=MT.GETSUMMARY(…)Aggregates
=MT.STATUS()Auth / connection status
=MT.VERSION()Add-in version info
=MT.APICALL(…)Generic API path
=MT.RELOADFUNCTIONS()Reload OpenAPI functions
=MT.LISTENDPOINTS()Endpoints and permissions

API functions (OpenAPI)

After reload, your API may expose functions such as =MT.GETUSERS(). Names follow the HTTP verb and path. Only permitted endpoints are registered.
